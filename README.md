# Customer Churn Analysis Dashboard

## Overview
This project analyzes customer churn using Power BI to identify patterns in customer behavior and retention. The dashboard explores churn across geography, gender, age groups, and number of products to support data-driven business decisions.

## Tools Used
- **Power BI** – Dashboard development and data visualization
- **DAX** – KPI calculations and churn rate measures

## Key Insights
- Germany has a higher churn rate than Spain and France.
- Older customer groups show higher churn rates than younger groups.
- Churn rates vary across customer segments and the number of products held.

## Recommendations
- Focus on improving customer retention in high-churn regions.
- Investigate the reasons behind higher churn among older customers.
- Develop targeted retention strategies based on customer behavior and segment-level insights.

## Project Files
- Power BI dashboard (`.pbix`)
- Python (`.ipynb`)
- Cleaned dataset (`.csv`)
- Dashboard screenshots

## Objective
To transform customer data into actionable insights using data visualization and analysis, helping businesses understand churn patterns and identify opportunities to improve customer retention.
